# 🏨 Hotel Management System

A console-based Hotel Management System built using Python and Object-Oriented Programming (OOP). The project demonstrates hotel data management, customer booking management, searching, sorting, and menu-driven interaction.

---

## 📌 Project Overview

The Hotel Management System is a beginner-friendly Python application designed to simulate basic hotel management operations. It allows users to store hotel information, display hotel details, search hotels by city, sort hotel records, and view customer booking information.

This project is intended for learning Python programming, Object-Oriented Programming (OOP), and basic data management techniques.

---

## ✨ Features

- Display all hotel records
- Display customer booking details
- Search hotels by city
- Sort hotels alphabetically
- Sort hotels by rating
- Sort hotels by available rooms
- Menu-driven console interface
- Exception handling for invalid user input
- Modular and object-oriented design

---

## 🛠 Technologies Used

- Python 3
- Object-Oriented Programming (OOP)

## ⚙ Installation

1. Clone the repository

```bash

```

2. Move into the project folder

```bash
cd Hotel-Management-System
```

3. Run the project

```bash
python hotel_management.py
```
